## 23.1 Monetization & Value Architecture

SmartZen operates on a B2B SaaS and enterprise success model:

```
[Universities] ──► Free Baseline Campus Tier / Annual Enterprise SLA
[Employers]    ──► Tiered Subscription (Seats + Search) + Placement Success Fees
[Candidates]   ──► 100% Free Lifetime Portfolio & Verification Access
```

## 23.3 Billing State Machine & Entitlement Enforcement

```
[TRIAL] ──► [ACTIVE] ──► [PAST_DUE] ──► [DELINQUENT] ──► [CANCELED]
```

* **Grace Period:** 7 calendar days on `PAST_DUE` before search functionality is gated.
* **Payment Gateways:** Stripe for global enterprise payments; Razorpay for domestic INR invoicing and GST compliance.
* **Usage Quotas:** Enforced atomically via Redis token buckets to prevent concurrent search limit breaches.
