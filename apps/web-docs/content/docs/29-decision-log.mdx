## 29.2 Strategic Trade-Off Decisions

1. **Self-Hosted VPS vs Premature Managed Cloud:** Opted for a high-end dedicated VPS over high-cost managed AWS services during current pilot phase, reducing operating expenses by $85\%$ while engineering strict 12-factor boundaries for seamless future migration.
2. **BARS Criterion-Referenced Scoring vs Percentiles:** Chose objective criterion-based cutoffs to ensure that a "Gold" tier badge represents demonstrable competence regardless of who else took the assessment that week.
