# Team Charter & Module Ownership

Ownership across the HireKiwi monorepo is enforced mechanically via `.github/CODEOWNERS` and authoritative team guidelines ([`TEAM.md`](file:///d:/Work's/Infinitica/hirekiwi/TEAM.md)).

Direct merges into another engineer's owned module are blocked; changes must be submitted via pull request and approved by the designated code owner.

## Contract-First Development Protocol

1. **Schema Authority:** Shared domain models and API contracts live exclusively in `packages/contracts`.
2. **Consumer Proposal:** Feature developers propose new endpoint contracts via PR to `packages/contracts`.
3. **Architectural Review:** Only the System Architect (`@brittytino`) may merge contract changes.
4. **Parallel Implementation:** Frontend and backend engineers develop against the merged Zod contracts without blocking each other.
5. **Quality Gates:** Every PR must satisfy:
   ```bash
   pnpm lint
   pnpm typecheck
   pnpm test
   pnpm format:check
   ```
   PR diffs are capped at **400 hand-written lines of code** to preserve review throughput and code quality.
