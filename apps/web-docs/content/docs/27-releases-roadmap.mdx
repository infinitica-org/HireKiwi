## 27.2 Version Breakdown: Deep Specification

### 1. v1.0.0 — Minimum Marketable Product (MMP Concierge Pilot)

- **Goal:** Validate that institutional students complete verified profiles and that universities can mediate candidate shortlists without data-dump aggregators.
- **Delivered Capabilities:**
  - Institutional student roster claiming via university domain emails.
  - Baseline student capability profile: declared skills, GitHub repository linking, and L1 cognitive/coding assessment.
  - Concierge TPO-mediated shortlisting: corporate JDs routed through university TPOs who generate curated candidate cohorts.
  - Public verification surface (`web-verify`): unauthenticated, tamper-evident cryptographic certificate view for skeptical recruiters.

### 2. v1.1.0 — Defensible Profile & Work-Experience Voucher Engine

- **Goal:** Eliminate candidate resume inflation by verifying real-world work claims against direct employer attestations.
- **Delivered Capabilities:**
  - **Work-Experience Voucher Engine:** Moves work experience from unverified claims to cryptographically signed verification vouchers.
  - **Strict Offer Letter Classification:** PDF uploads of offer letters, appointment orders, or joining emails are automatically flagged as `INVALID_DOCUMENT_TYPE`. Only relieving letters and completion certificates are accepted for review.
  - **Official Domain Verifier Routing:** The system validates verifier email domains against corporate websites, rejecting free webmail providers (`@gmail.com`, `@yahoo.com`).
  - **State Machine Cadence:** Automated reminder sent after 6 hours; moves to `VERIFICATION_EXPIRED` after 48 hours without spamming, issuing a clean restart with updated contact details.
  - **TPO / Ops Real-Time Voucher Radar:** Operational dashboard displaying verification stage, employer domain, and remaining SLA timers across the candidate cohort.

### 3. v1.2.0 — Recruiter Self-Serve & Explainable Match Engine

- **Goal:** Enable recruiters to configure requisitions and receive instant, explainable shortlists in 3 minutes without requiring manual TPO meetings.
- **Delivered Capabilities:**
  - **Self-Serve Requisition Builder:** Employers define competency requirements with explicit BARS minimum proficiency thresholds.
  - **Explainable Matching Telemetry:** Candidate match scores are broken down into transparent dimensions (Vector Semantic Similarity + Rubric Score Coverage + Verified Evidence Ratio).
  - **Candidate Consent & Opt-In:** Candidates receive notification of match inclusion and can accept or decline participation before their dossier is shared with recruiters.

### 4. v1.3.0 — Outcome Telemetry & Enterprise Multi-Campus Scale

- **Goal:** Statistically prove that Gold-tier candidates achieve higher conversion and faster time-to-hire compared to traditional campus baselines.
- **Delivered Capabilities:**
  - **Conversion Analytics:** Tracks hiring conversion rates across Gold, Silver, and Bronze tiers against university baseline metrics.
  - **Closed-Loop Calibration:** Post-interview feedback from corporate interviewers recalibrates platform scoring rubrics.
  - **Enterprise Multi-Campus Federation:** Allows enterprise hiring teams to run unified multi-institution hiring drives across dozens of partnered colleges simultaneously.

## 27.3 Reengineering Backlog Cleanup: Deprecations & Architectural Upgrades

During the transition from initial experimental prototypes to the enterprise-grade v1.0–v1.3 architecture, significant legacy technical debt was purged and re-engineered:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    BACKLOG CLEANUP & REENGINEERING AUDIT                    │
├─────────────────────────┬───────────────────────┬───────────────────────────┤
│ LEGACY BACKLOG PATTERN  │ RESOLUTION / STATUS   │ ARCHITECTURAL RATIONALE   │
├─────────────────────────┼───────────────────────┼───────────────────────────┤
│ Bulk Resume Scraping /  │ PERMANENTLY REMOVED   │ Violates DPDP Act 2023 and│
│ CSV Candidate Export    │ (Anti-Pattern)        │ core anti-aggregator bet. │
├─────────────────────────┼───────────────────────┼───────────────────────────┤
│ Offer Letter Upload as  │ DEPRECATED & REJECTED │ Offer letters do not prove│
│ Work Experience Proof   │ (INVALID_DOC_TYPE)    │ completed work experience.│
├─────────────────────────┼───────────────────────┼───────────────────────────┤
│ Synchronous AI          │ RE-ENGINEERED TO      │ Heavy LLM calls during    │
│ Assessment Endpoints    │ BullMQ ASYNC WORKERS  │ peak exams take down API. │
├─────────────────────────┼───────────────────────┼───────────────────────────┤
│ Single Super Admin      │ REPLACED WITH GRANULAR│ Root admin account is a   │
│ Monolithic Account      │ MULTI-TENANT RBAC     │ compliance & audit risk.  │
├─────────────────────────┼───────────────────────┼───────────────────────────┤
│ Multi-Host VPS Topology │ CONSOLIDATED TO SINGLE│ Eliminates sync lag, split│
│ (kvm2 / kvm4 clusters)  │ VPS BLUE-GREEN        │ brain, and high idle cost.│
└─────────────────────────┴───────────────────────┴───────────────────────────┘
```

1. **Purged Bulk Data Export Endpoints:** All legacy backlog stories requesting CSV or bulk JSON candidate exports were permanently rejected and removed from sprint backlogs. SmartKiwi provides curated candidate cards and verified dossiers only.
2. **Re-engineered Work Experience Verification:** Replaced passive PDF attachment storage with the active 4-state corporate voucher state machine with official domain checks.
3. **Async Queue Architecture for AI:** Converted synchronous `/evaluate` REST endpoints into asynchronous BullMQ jobs backed by Redis, protecting API responsiveness under peak test concurrency.
4. **Clean Infrastructure Consolidation:** All legacy scripts referencing `kvm2` and `kvm4` were deleted. Deployments are unified on a Single High-End VPS utilizing automated Caddy Blue-Green zero-downtime container swaps (`scripts/blue-green-deploy.sh`).
