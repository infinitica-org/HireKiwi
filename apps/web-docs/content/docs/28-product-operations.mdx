## 28.1 Observability & Monitoring Stack

SmartKiwi deploys an integrated metrics and logging pipeline:

- **Metrics Collection:** Prometheus scrapes `/metrics` endpoints on `api-core` (authenticated via `METRICS_SCRAPE_TOKEN`).
- **Visualizations:** Grafana dashboards monitor event latency, API error budgets, Redis memory utilization, and BullMQ queue lag.
- **Log Aggregation:** Fluentbit streams container stdout/stderr to centralized storage with sensitive PII masking filters.

## 28.2 Disaster Recovery & Database Backups

```
[PostgreSQL Database] ──(Daily 03:00 UTC pg_dump)──► [Local Encrypted GZIP] ──(S3 Sync)──► [Offsite Cold Storage]
```

- **RPO (Recovery Point Objective):** < 1 hour (WAL archiving enabled).
- **RTO (Recovery Time Objective):** < 30 minutes for complete database restoration.
- **Automated Weekly Restore Drill:** A scheduled cron job validates backup integrity by restoring the latest dump onto an isolated test container.
