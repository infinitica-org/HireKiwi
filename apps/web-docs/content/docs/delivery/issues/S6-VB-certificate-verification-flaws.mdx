# Peer Audit & Flaw Report — Certificate Verification & Trust Chain

> **Auditor:** Vedika G (Data & Content Engineer)  
> **Module Owner / Assignee:** Vishal Bharath R  
> **Scope:** `web-verify`, `candidate-certificates` endpoint security, URL signature tampering, non-existent UUID handling, and print layout rendering.  
> **Date:** 2026-09-29

---

## Audit Findings & Verification Flaws Assigned to Vishal Bharath R

### Flaw 1 — Unhandled Certificate Signature Hash Tampering (High Severity)

- **Description:** Previously, probing certificate verification URLs (`/cert/[id]?sig=...`) with modified or altered hex signature hashes failed silently or rendered positive validation alerts without checking cryptographic signature integrity.
- **Security Impact:** Allows spoofing of certificate validity by altering URL parameters or hex signature strings.
- **Remediation:** Added HMAC-SHA256 signature verification in `apps/web-verify/src/lib/cert-signature.ts`. If any hex character is altered or corrupted, a prominent `Tamper Warning` alert is rendered and a `[SECURITY_EVENT]` audit log is emitted.
- **Verification Status:** Tested & Verified (Adversarial Test 1 passing).

---

### Flaw 2 — Stack Trace Leakage & Uncaught 500 Exceptions on Invalid Certificate UUIDs (Medium Severity)

- **Description:** Requesting non-existent certificate UUIDs or malformed UUID strings resulted in unhandled Prisma/NestJS exception tracebacks leaking internal database schemas and stack traces to public callers.
- **Security Impact:** Information disclosure of internal framework, database schema, and server stack traces to unauthenticated external users.
- **Remediation:** Added strict UUID format and non-existent UUID guard (`isValidUuid`) in `apps/web-verify/src/app/cert/[id]/page.tsx` that triggers Next.js `notFound()` 404 wall (`not-found.tsx`), producing clean, informative 404 pages with zero stack trace leakage.
- **Verification Status:** Tested & Verified (Adversarial Test 2 passing).

---

### Flaw 3 — Multi-Page Page Break & Misaligned Certificate Print CSS (Low Severity)

- **Description:** Printing certificate pages rendered header navigation buttons, footer links, and unconstrained container widths across page breaks, failing single-page PDF/print alignment in Chrome, Firefox, and Safari.
- **Remediation:** Introduced `@media print` rules in `apps/web-verify/src/app/globals.css` with `@page { size: A4 portrait; margin: 12mm; }`, hiding interactive elements (`.no-print`, `header`, `footer`) and preventing page breaks inside `.cert-print-container`.
- **Verification Status:** Tested & Verified across Chrome, Firefox, and Safari (Adversarial Test 3 passing).
