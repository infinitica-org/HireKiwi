## 22.1 Telemetry Architecture

SmartKiwi captures behavioral, operational, and system performance telemetry via Redpanda event streams consumed by ClickHouse and visualized in Grafana:

```
[Web / API Event] ──► [Redpanda: telemetry.events.v1] ──► [ClickHouse OLAP] ──► [Grafana Dashboards]
```

## 22.3 University & Employer Cohort Dashboards

- **University Placements Dashboard:** Tracks live CTC distribution, offer acceptance rates, department-wise capability percentiles, and NIRF accreditation compliance indicators.
- **Employer Hiring Efficiency Dashboard:** Displays funnel conversion from candidate discovery to technical interview to offer acceptance, quantifying recruitment hours saved compared to legacy ATS screening.

## 22.4 Continuous Experimentation (A/B Testing)

- Controlled rollout of recommendation weights ($w_v, w_c, w_b$) across matching cohorts.
- Prompt engineering experiments evaluated via offline Golden Dataset runs before multi-armed bandit traffic allocation.
