## 25.2 Non-Functional Requirements (NFRs)

* **Latency (p95):** Read API endpoints must respond in < 80ms; next-item assessment delivery in < 50ms; complex semantic search in < 350ms.
* **Throughput:** System must sustain 5,000 concurrent active assessment takers per single High-End VPS instance.
* **Availability:** $99.95\%$ uptime target for public verification and candidate profile endpoints.
* **Security SLA:** Zero critical CVEs in production dependencies; automated dependency audit on every pull request.

---

## 25.3 Business Invariants & Constraints

1. **One Active Offer Policy:** When a candidate accepts an official job offer, their status automatically flags other pending applications as `LOCKED_PLACED`, unless the university authorizes "Dream Offer" participation.
2. **Contract-First Constraint:** No database model or API endpoint may be merged into `dev` without corresponding DTO schemas in `packages/contracts`.
3. **No Direct Production Pushes:** All code changes must enter via pull request branches with 100% passing automated CI checks.
