## 19.1 API Architecture Standards & Conventions

HireKiwi provides a secure, versioned RESTful API exposed through `api.becomesmart.online/v1`:

- **Protocol & Encoding:** HTTPS with mandatory TLS 1.3; UTF-8 JSON payloads (`Content-Type: application/json`).
- **Authentication:** Stateless JSON Web Tokens (JWT, 15-minute TTL) with HttpOnly refresh cookies; or Bearer API keys (`sk_live_*` for production enterprise access).
- **Idempotency Invariant:** All mutating endpoints (`POST`, `PUT`, `PATCH`) support the `Idempotency-Key: {UUIDv4}` header. Replays within 24 hours return identical responses without re-executing business logic.
- **Error Standards:** Conforms strictly to RFC 7807 (Problem Details for HTTP APIs):

```json
{
  "type": "https://docs.becomesmart.online/errors/COMPETENCY_FLOOR_NOT_MET",
  "title": "Unmet Competency Threshold",
  "status": 422,
  "detail": "Application requires minimum Silver tier (BARS >= 3.5) in Distributed Caching.",
  "instance": "/v1/tpo/drives/shortlist",
  "code": "SMART_422_COMPETENCY_FLOOR",
  "timestamp": "2026-09-30T16:00:00Z"
}
```

## 19.2 Comprehensive REST Endpoint Catalogue

### 1. Authentication & Tenancy Service (`/v1/auth`)

| Method | Endpoint                | Description                                                      | Auth Scopes   |
| :----- | :---------------------- | :--------------------------------------------------------------- | :------------ |
| `POST` | `/v1/auth/login`        | Email/password session login with multi-tenant domain resolution | Public        |
| `POST` | `/v1/auth/sso/callback` | Microsoft Entra ID / Google Workspace OIDC token callback        | Public        |
| `POST` | `/v1/auth/refresh`      | Refreshes short-lived JWT using secure HttpOnly cookie           | Session       |
| `POST` | `/v1/auth/logout`       | Revokes current session token and clears refresh cookie          | Authenticated |

### 2. Candidate & Evidence Service (`/v1/candidates`)

| Method | Endpoint                              | Description                                                       | Auth Scopes        |
| :----- | :------------------------------------ | :---------------------------------------------------------------- | :----------------- |
| `GET`  | `/v1/candidates/profile`              | Fetches authenticated candidate profile and verified competencies | `CANDIDATE`        |
| `POST` | `/v1/candidates/evidence/github`      | Initiates GitHub OAuth repository linking and AST code scan       | `CANDIDATE`        |
| `POST` | `/v1/candidates/evidence/voucher`     | Submits work-experience attestation claim (Rejects offer letters) | `CANDIDATE`        |
| `GET`  | `/v1/candidates/evidence/voucher/:id` | Queries voucher status, reminder cadence, and corporate domain    | `CANDIDATE`, `TPO` |

### 3. Assessment & Examination Service (`/v1/assessments`)

| Method | Endpoint                        | Description                                                    | Auth Scopes |
| :----- | :------------------------------ | :------------------------------------------------------------- | :---------- |
| `POST` | `/v1/assessments/start`         | Initializes examination session; schedules BullMQ server timer | `CANDIDATE` |

| `POST` | `/v1/assessments/finish`        | Concludes assessment; triggers BARS rubric grading worker      | `CANDIDATE` |

### 4. University Placement Service (`/v1/tpo`)

| Method | Endpoint                      | Description                                                         | Auth Scopes         |
| :----- | :---------------------------- | :------------------------------------------------------------------ | :------------------ |

### 5. Corporate Recruiter Pipeline Service (`/v1/company`)

| Method  | Endpoint                                | Description                                                         | Auth Scopes     |
| :------ | :-------------------------------------- | :------------------------------------------------------------------ | :-------------- |

### 6. Public Verification Surface (`/v1/verify`)

| Method | Endpoint                          | Description                                                     | Auth Scopes      |
| :----- | :-------------------------------- | :-------------------------------------------------------------- | :--------------- |
| `GET`  | `/v1/verify/certificates/:certId` | Validates HMAC-SHA256 signature and returns verified badge info | Public (No Auth) |

## 19.3 ATS Webhook Dispatch Engine

Enterprise recruiters receive real-time webhook updates when candidate milestones occur:

- **Event Types:** `candidate.verified`, `application.shortlisted`, `interview.scheduled`, `offer.accepted`.
- **Payload Verification:** Webhook payloads include an `X-HireKiwi-Signature` computed via HMAC-SHA256 using the customer's webhook signing secret.

```json
{
  "eventId": "evt_991823ab-4122-4819",
  "eventType": "candidate.verified",
  "timestamp": "2026-09-30T16:15:00Z",
  "data": {
    "candidateId": "cand_univ_55102",
    "competency": "Node.js Distributed Concurrency",
    "tier": "GOLD",
    "barsScore": 4.65,
    "certificateUrl": "https://becomesmart.online/verify/cert_h7x92j0"
  }
}
```
