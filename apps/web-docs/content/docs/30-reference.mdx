## 30.2 Error Code Catalogue

| HTTP Status | Error Code | Description | User Remedy |
| :--- | :--- | :--- | :--- |
| `401` | `SMART_401_AUTH_EXPIRED` | JWT bearer token has expired or is invalid. | Re-authenticate via institutional SSO. |
| `403` | `SMART_403_TENANT_FORBIDDEN` | User does not hold permissions within target tenant. | Contact campus or employer administrator. |
| `422` | `SMART_422_COMPETENCY_FLOOR` | Candidate does not satisfy minimum BARS tier. | Complete recommended project defense. |
| `429` | `SMART_429_RATE_LIMITED` | Sliding window rate limit exceeded (100 req/min). | Back off requests for 60 seconds. |
| `503` | `SMART_503_INFERENCE_DEGRADED` | External LLM unavailable; regex fallback active. | System operating in deterministic fallback mode. |

## 30.3 Core Event Catalogue (Redpanda / Kafka)

* `candidate.onboarded.v1`: Candidate claims profile and completes initial survey.
* `evidence.submitted.v1`: New GitHub repo or certificate registered for verification.
* `defense.completed.v1`: Proctored AI project defense session concluded and transcribed.
* `capability.tier_assigned.v1`: New BARS tier (Gold/Silver/Bronze) assigned and HMAC signed.
* `match.generated.v1`: Match score computed between candidate and active job opening.
* `application.status_changed.v1`: Candidate advances or is rejected in recruiter pipeline.
* `telemetry.purge_executed.v1`: Nightly DPDP purge script completes deletion of expired snapshots.
